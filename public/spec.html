Collaborative
Text Editor

Éditeur de texte collaboratif temps réel simulant des interactions multi-utilisateurs. Architecture React 19, CRDT via Yjs, zéro re-render global lors de la saisie.

React 19 + Vite Yjs + CodeMirror 6 Zustand Tailwind CSS Playwright Storybook 8
🚀 Voir le Live Demo 💻 Code Source GitHub 📚 Storybook Docs
01

Stack technique

Build Vite + React 19 Rapide, pas d'overhead SSR inutile. 100% client-side.
Collaboration Yjs + y-codemirror.next CRDT natif. Curseurs sans re-render React via Decorations.
Éditeur CodeMirror 6 Modulaire, extensible. API Decorations pour les curseurs.
State Management Zustand Selectors granulaires. Zéro boilerplate vs Redux.
Styling Tailwind CSS (pur) Pas de Shadcn. Montre la maîtrise CSS directe.
Faux utilisateurs @faker-js/faker Noms, avatars et comportements réalistes pour les bots.
Tests unitaires Vitest + Testing Library Intégration native Vite. Rapide, compatible jsdom.
Tests E2E Playwright Standard industrie. Cross-browser, screenshots auto.
Documentation Storybook 8 Documentation vivante. Déployée automatiquement sur GH Pages.
Git Hooks Husky + lint-staged Lint + format obligatoires avant chaque commit.
Utilitaires date-fns + lucide-react Léger, composable. Pas de moment.js.
Types TypeScript Strict noImplicitAny, exactOptionalPropertyTypes, noUnusedLocals.

Fonctionnalités

🟢 Collaboration CRDT — 3 bots simulés via Yjs. Convergence mathématiquement garantie sans serveur central.
🟡 Simulation réseau — Latence aléatoire 100–1500ms. Perte de paquets à 1%. Statut de connexion dynamique.
🔵 Curseurs multiples — Via CodeMirror Decorations. Zéro re-render React lors du déplacement des curseurs.
⚡ Undo / Redo — Natif via Yjs UndoManager. Scope utilisateur uniquement (les actions des bots ne sont pas undoable).
📋 Journal d'activité — Log chronologique de toutes les opérations. Virtualisé pour éviter les fuites mémoire.
💬 Module de chat — Onglet dans le panneau droit. Messages attribués avec couleur d'avatar.
🌙 Dark mode — Toggle global. Classe dark sur html. Persisté en localStorage.
📱 Responsive — Panneaux latéraux collapsibles sur mobile. Layout flexible via Tailwind.
🔢 Numérotation de lignes — Extension CodeMirror native. Mise à jour sans re-render React.
📊 Console de débogage — Footer affichant taille doc, latence simulée, mode de synchronisation en temps réel.
04

Flux de données

ℹ️
L'état du texte ne vit jamais dans un useState React. Il vit dans l'instance Yjs/CodeMirror. React ne re-rend que les composants UI périphériques (header, logs, footer) via Zustand selectors.
Flux de données — Architecture Diagram 
Utilisateur tape
      │
      ▼
CodeMirror (DOM natif — aucun React ici)
      │ update binaire Yjs
      ▼
MockNetworkProvider
      │ setTimeout(100–1500ms)  ←── 1% probabilité de drop
      ▼
sharedDoc (Y.Doc commun)
      │
      ├──► BotSimulator (setInterval) ──► lit/écrit dans sharedDoc
      │
      ▼
MockNetworkProvider (remote update)
      │ setTimeout (latence retour)
      ▼
localDoc ──► CodeMirror ──► DOM (curseurs via Decorations)
      │
      └──► Zustand (latence, statut) ──► Header / Footer React
05

Stratégie de tests

Niveau Outil Ce qui est testé Commande
Unitaire Vitest + Testing Library Composants isolés, hooks, stores Zustand pnpm test
Composants Storybook 8 Tous les états visuels (Connecté, Syncing, Déco...) pnpm storybook
E2E Playwright Flux complets : titre éditable, dark mode, bots, logs pnpm test:e2e
Couverture Vitest coverage Rapport HTML + badge CI pnpm test:coverage
⚠️
Règle : Tout nouveau composant doit avoir sa story Storybook + au moins un test unitaire. Aucun any, aucun // @ts-ignore accepté. Le CI bloque les PRs qui violent ces règles.

Convention Git

Branche Usage

develop Intégration — branche de travail principale
feat/nom Nouvelle fonctionnalité
fix/nom Correction de bug
chore/nom Maintenance, deps, config
Exemples de commits conventionnels Git 
feat(editor): add line numbers to CodeMirror
fix(simulation): prevent bot updates after component unmount
perf(store): memoize log selectors to avoid re-renders
test(e2e): add dark mode toggle playwright spec
chore(deps): upgrade yjs to 13.6.19
docs(arch): document CRDT conflict resolution strategy
